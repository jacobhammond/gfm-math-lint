# Security Policy

## Supported Versions

Only the latest release of `gfm-math-lint` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `gfm-math-lint`, please report it privately:

- **Preferred method:** Use GitHub's private vulnerability reporting feature on the repository via the [Security Advisory](https://github.com/jacobhammond/gfm-math-lint/security/advisories/new) tab.
- **Alternative:** Email the maintainer at `114956625+jacobhammond@users.noreply.github.com` with the subject `[SECURITY] gfm-math-lint vulnerability report`.

### What to include in your report

- Description of the vulnerability and its potential impact.
- Steps to reproduce the issue, including minimal Markdown samples or CLI invocations.
- Proposed patch or mitigation if available.

### Response Timeline

- **Initial acknowledgment:** Within 48 hours.
- **Triage and impact assessment:** Within 5 business days.
- **Patch release and coordinated disclosure:** Within 14 business days of verification.

Please do not open public GitHub issues or discuss security vulnerabilities publicly until a patch has been released.
